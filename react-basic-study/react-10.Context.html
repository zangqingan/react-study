1.Context

        1.概述
        在react中通过 props 将信息从父组件传递到子组件、如果你必须通过许多中间组件向下传递 props，或是在你应用中的许多组件需要相同的信息，传递 props 会变的十分冗长和不便（props逐级透传）。
        Context 提供了一种在组件之间共享值的方式允许父组件向其下层无论多深的任何组件提供信息，而不必显式地通过 props 传递。
        它通常用于在组件树中传递全局状态，例如用户认证信息、主题设置等。

        2.实现
        通过以下三个步骤来实现：
      
          1.创建 一个 context并将其导出。
          2.在需要数据的组件内，使用useContext Hook 和刚刚创建的 context。
          3.在指定数据的组件中用 context provider 包裹起来，提供这个 context。
