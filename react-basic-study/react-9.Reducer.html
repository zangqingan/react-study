1.Reducer


      当组件内的state状态很多时可以将组件的所有状态更新逻辑整合到一个外部函数中、这个函数叫作 reducer 减少的意思。
      可以理解为状态管理器,有点类似于vux中的action、提交改变会自动执行对于逻辑。
      它接收当前的状态(state)和一个动作(action)对象作为参数、并基于这个动作计算出并返回下一个新的状态。
      function myReducer(state, action) {
        // 根据 action 的类型 type 来决定如何更新状态
        switch (action.type) {
          case 'ACTION_TYPE_1':
            // 返回新的状态（不要直接修改原状态！）
            return { ...state, key: action.payload };
          case 'ACTION_TYPE_2':
            return { ...state, anotherKey: state.anotherKey + 1 };
          default:
            // 如果 action 不匹配、返回原状态
            return state;
        }
      }
      也就是说 Reducer 可以整合组件的状态更新逻辑、在 React 中、Reducer 通常与 useReducer Hook 一起使用。
      useReducer 它是 useState 的一种替代方案、适用于状态逻辑复杂或包含多个子值的场景。

      本质上 Reducer 是处理状态的另一种方式。你可以通过三个步骤将 useState 迁移到 useReducer
        1、将设置状态的逻辑 修改成 dispatch 的一个 action
        2、编写 一个 reducer 函数、reducer 函数就是你放置状态逻辑的地方。它接受两个参数、分别为当前 state 和 action 对象、并且返回的是更新后的 state。
        3、在你的组件中 使用 reducer。
        useReducer 钩子接受 2 个参数：
          一个 reducer 函数
          一个初始的 state
        它返回如下内容
          一个有状态的值 -当前状态
          一个 dispatch 派发动作的函数(用来 “派发” 用户操作给 reducer)
        import { useReducer } from 'react';
        // 1. 定义 reducer 函数
        function counterReducer(state,action) {
          switch (action.type) {
            case 'increment':
              return { count: state.count + 1 };
            case 'decrement':
              return { count: state.count - 1 };
            case 'reset':
              return { count: 0 };
            default:
              throw new Error(`Unhandled action type: ${action.type}`);
          }
        }
        function Counter() {
          // 2. 在组件中使用 useReducer
          // useReducer 返回当前状态和一个派发动作的函数 dispatch
          const [state, dispatch] = useReducer(counterReducer, { count: 0 });

          
        }
        dispatch 函数一般会传入一个对象叫做 “action”，按照惯例，我们通常会添加一个字符串类型的 type 字段来描述发生了什么，并通过其它字段传递额外的信息。
        dispatch(
          // "action" 对象：
          {
            type: 'deleted',
            id: taskId,
            // 其它字段...
          }
        );
